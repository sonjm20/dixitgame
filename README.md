# dixitgame

딕싯게임을 온라인으로 즐기는 웹앱

보드게임 **딕싯(Dixit)** 룰을 따르는 실시간 멀티플레이어 웹앱의 뼈대(skeleton) 코드입니다.

## 기술 스택

- 백엔드: Node.js, Express, Socket.io
- 프론트엔드: HTML, CSS, Vanilla JavaScript

## 프로젝트 구조

```
dixitgame/
├── package.json
├── images/                # 카드 이미지 리소스 (사용자가 직접 채워 넣는 폴더)
│   └── .gitkeep
├── server/
│   ├── server.js          # Express + Socket.io 엔트리포인트, 이벤트 핸들러
│   ├── roomManager.js      # Room/RoomManager 클래스 (방 상태, 턴, 점수 계산 로직)
│   └── imageLoader.js      # images/ 폴더의 카드 이미지 목록 로드
└── public/
    ├── index.html          # 화면(랜딩/대기실/게임/결과) 마크업
    ├── style.css
    └── script.js           # Socket.io 클라이언트, 화면 전환 및 렌더링
```

## 카드 이미지 준비

`images/` 폴더에 카드로 사용할 이미지 파일(`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`)을 넣어주세요.
예: 로컬의 `D:\OneDrive - 인천원당초등학교\claude_pc\Gamification\dixit` 폴더에 있는 이미지를
이 프로젝트의 `images/` 폴더로 복사합니다.

- 서버 시작 시 `images/` 폴더를 스캔해 카드 목록을 만듭니다.
- 최소 참가 인원(3명) × 손패(6장) = 18장 이상의 이미지가 있어야 방을 만들고 게임을 시작할 수 있습니다.
- 이미지는 `express.static`으로 `/images/파일명` 경로에 서빙됩니다.

## 실행 방법

```bash
npm install
npm start
# 개발 중에는 nodemon으로 자동 재시작
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 (여러 창/기기에서 접속해 함께 테스트).

## 핵심 로직 요약

### 방 시스템
- 방 생성 시 4자리 숫자 코드 발급, 생성한 유저가 방장(host)이 됨
- 참가자는 닉네임 + 방 코드로 입장
- 서버 전체 방 개수 최대 **20개**, 방당 인원 **3~6명** 제한 (가득 찬 방/시작된 방 입장 차단)
- Socket.io의 `socket.join(roomCode)` + `io.to(roomCode).emit(...)` 으로 방 단위 이벤트 브로드캐스트를 분리

### 게임 진행 (Room 상태 머신: `lobby → clue → submit → vote → reveal → clue → ...`)
1. **카드 분배**: 방별로 이미지 풀을 셔플해 각 플레이어에게 6장씩 배분
2. **출제자 턴(clue)**: 출제자가 손패 1장 + 제시어 텍스트 제출
3. **카드 제출(submit)**: 나머지 플레이어가 손패에서 카드를 비공개로 제출 (전원 제출 시 자동으로 투표 단계로 전환)
4. **투표(vote)**: 제출된 카드를 셔플해 공개, 출제자를 제외한 플레이어가 진짜 카드에 투표 (자기 카드 투표 불가)
5. **점수 계산(reveal)**:
   - 전원 정답 또는 전원 오답 → 출제자 0점, 나머지 전원 2점
   - 그 외 → 출제자 + 정답자 각 3점
   - 보너스: 자신의 가짜 카드에 투표한 사람 수만큼 1점씩 추가
6. **턴 넘김**: 사용한 카드 버리고 1장 보충, 다음 사람에게 출제자 턴 이동

### 예외 처리
- 닉네임/방 코드 미입력, 존재하지 않는 방, 방 가득 참(6명), 이미 시작된 방 입장 차단
- 서버 전체 방 20개 초과 시 생성 차단
- 방장이 아닌 유저의 게임 시작/다음 라운드 요청 차단
- 최소 인원(3명) 미만일 때 시작 차단, 게임 도중 인원 미달 시 게임 종료 처리
- 카드 이미지 부족 시 게임 시작/진행 차단 및 안내 메시지
- 자신의 카드에 투표, 중복 제출/투표 등 규칙 위반 요청 차단
